# Changesets

This folder is managed by [changesets](https://github.com/changesets/changesets).

- Run `pnpm changeset` to record a version bump + changelog entry for a change.
- Run `pnpm version-packages` to apply pending changesets (bumps versions, writes CHANGELOGs).
- Run `pnpm release` to build and publish.

See the [common questions](https://github.com/changesets/changesets/blob/main/docs/common-questions.md) for details.
